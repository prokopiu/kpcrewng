# The kpcrew_prefs Folder
This holds the following types of preferences:

- application.preferences: The settings for the KPCrewNG / KPHWNG application
- briefing.preferences: Saves the current briefing state (in case there is a problem and the lua scripts had to be restarted)
- [ICAO].preferences: The aircraft type specific settings (these are quite large but will be pruned in the next weeks).

DFLT.preferences is the generic one which also defines the structure of the preferences. **Please do not modify this one.**
