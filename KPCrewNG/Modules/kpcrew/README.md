# The kpcrew Folder

This folder holds ALL submodules needed to run KPCrewNG and KPHWNG. They are collected in one subfolder for easy install/uninstall.

It also contains external dependencies such as xml2lua.

| File / Folder  | Description                                     |
|----------------|-------------------------------------------------|
| Addon   | The main code library for kpcrewng |
| addons  | Addon/Aircraft specific configurations |
| xmlhandler| library for XML file handling (Simbrief) |
|----------------|-------------------------------------------------|
| acft_select.lua|Set the correct SOP and configuration for an XP aircraft|
|imgui_utils.lua|All the IMGUI functionalities for rendering the windows|
|kpcrew_draw.lua|Draws all the windows and menus|
|metar.lua|Code to interpret METAR files|
|metargen.lua|Code to create a metar from XP weather (deprecated)|
|nggenutils.lua|Library of utility functions for kpcrewng|
