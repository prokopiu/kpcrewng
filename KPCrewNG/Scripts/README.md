# SCRIPTS Folder of FlyWithLua
The files in this folder need to go the <xplane>\Resources\plugins\FlyWithLua\Scripts . Overwrite older versions. To disable KPCrewNG remove the below .lua files.

- kpcrewng.lua: Main script to run the whole KPCrewNG show
- kphwng.lua: Main script to run KPHWNG (if you do not want or need it rename or delete)
